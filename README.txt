# Portofolio Fitrah Di Jatmiko

Website portofolio modern dengan HTML, CSS, dan JavaScript.

## Struktur
- index.html
- style.css
- script.js
- assets/images/profile.jpg

## Menjalankan
Buka `index.html` di browser.

## Hosting
Upload seluruh isi folder ke hosting seperti InfinityFree, Netlify, atau Vercel.
Jangan mengubah lokasi `assets/images/profile.jpg` agar foto profil tetap tampil.
